# NABD AI Tutor v2 — استعادة index.ts وتوضيح أخطاء الخدمة

**لمن حذف محتوى index.ts:** لا تنشر ملفًا فارغًا. النسخة الجاهزة للنشر موجودة في **\`supabase/manual/nabd-tutor.ts\`**، وهي ملف واحد مكتمل دون اعتماد على ملفات إضافية، يمكنك نسخه كاملًا إلى \`index.ts\` داخل دالة Supabase الحالية التي ينتهي رابطها بـ \`/functions/v1/smart-processor\`.

## أسرع طريقة من الهاتف

1. افتح [الملف الجاهز](../supabase/manual/nabd-tutor.ts) في GitHub ثم اضغط **Raw** (النسخة الخام).
2. اختر نسخ الكل، وليس مقطعًا من منتصف الملف.
3. في Supabase Dashboard > **Edge Functions > nabd-tutor > Code > index.ts**، الصق كامل الملف مكان المحتوى الفارغ.
4. **لا تغيّر اسم الدالة أو رابطها**: يظل رابط الاستدعاء \`/functions/v1/smart-processor\`، ولو كان الاسم المعروض \`nabd-tutor\`.
5. اضغط **Deploy updates** بعد التأكد من اكتمال اللصق. لا تشغّل SQL Editor لهذا الكود.
6. في Edge Functions > **Secrets** تحقق من وجود الاسم \`OPENAI_API_KEY\` (قيمة المفتاح سرية؛ لا تشاركها). \`OPENAI_MODEL\` اختياري ويكون اختيار النموذج فيه متوافقًا مع حساب OpenAI API.
7. اترك **Verify JWT** والهوية مفعّلين. SQL الخاص بالحصص سبق إصلاحه ولا يحتاج إعادة تفعيل.
8. افتح صفحة التعلّم وسجّل الدخول ثم جرّب سؤالًا واحدًا. إذا ظهر رمز فشل جديد أرسله بدون أي مفتاح/توكن/بيانات مريض.

## ما الجديد في v2؟

- معالجة منظمة لـ HTTP 401/403/404/400/422 من OpenAI.
- تمييز \`credit_balance_exhausted\` و\`project_spend_limit_exceeded\` وأخطاء الحصة الحديثة عن \`rate_limit_exceeded\`.
- فصل أخطاء HTTP 500/502/503/504 كـ \`PROVIDER_UPSTREAM_ERROR\` (مشكلة في استجابة خادم الخدمة).
- فصل فشل اتصال خادم الأكاديمية بالمزوّد (\`PROVIDER_CONNECTION_ERROR\`) وJSON غير الصالح (\`PROVIDER_INVALID_RESPONSE\`).
- كتابة فئة الخطأ ورقم HTTP فقط في سجلات Edge Function، وليس مفتاح API أو نص السؤال أو نص خطأ المزوّد.
- ترويسة \`x-nabd-tutor-version: 2\` للتعرّف على النسخة المنشورة.
- بقاء التحقق من الطالب، أصل الموقع، حد الستة طلبات للدقيقة، مدخلات الصور التعليمية، حجب مفتاح OpenAI، وعدم حفظ ردود المزوّد \`store:false\`.

## ما الذي لا يفعله النشر؟

لا يضمن وجود رصيد في OpenAI API، ولا يزيل حدود الحساب أو أعطال الخدمة. لا يكفي امتلاك ChatGPT Plus لاستخدام واجهة OpenAI API. إصدار جديد من الكود لا يحل رفضًا صادرًا من المزوّد نفسه؛ وإنما يوضح حالته حتى نعالج السبب.

الاختبارات الآلية على GitHub تستعمل ردودًا **وهمية فقط**، ولا تتصل بحساب Supabase أو OpenAI الحقيقي.

## إذا أظهر النشر خطأ

راجع اسم الدالة الفعلي، وحالة **Secrets**، ورسالة الخطأ في **Logs** بعد إرسال سؤال واحد. لا تضع مفتاح API داخل index.ts، ولا تنسخ سجلات تحتوي Authorization أو JWT إلى المحادثة.
