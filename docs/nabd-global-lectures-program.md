# برنامج نبض الدولي للمحاضرات الطبية
## NABD Global Medical Lectures Program — التصور التنفيذي

**الحالة: 5 نوفمبر 2026 — قيد الإعداد.** لا توجد شراكات أو محاضرات أو مواعيد مؤكدة، ولا تسجيل مفتوح حاليًا. قائمة الجهات العشر المحتملة لا تعني وجود موافقات. لا تبدأ مراسلة الجهات إلا بتوجيه إداري منفصل.

### 1. الهوية والرسالة
- **الجهة:** أكاديمية نبض للعلوم الطبية.
- **الإشراف العام:** المؤسس والمدير العام محمد خالد العرجا.
- **الجمهور المستهدف:** طلبة الطب والعلوم الصحية في غزة وفق السعة التقنية.
- **التجربة:** محاضرات تطوعية مجانية عن بعد، مع مساحة للأسئلة والتفاعل.
- **الرؤية:** تقليل الفجوة في الوصول إلى المعرفة والخبرات الأكاديمية الدولية.
- **المبدأ:** تعاون إنساني وتعليمي واقعي، وشفافية كاملة بشأن الشراكات والمخرجات.

### 2. برنامج تجريبي لأربعة أسابيع
| الأسبوع | المحور | المثال المقترح | النمط |
|---|---|---|---|
| 1 | العلوم الأساسية | ربط التشريح ووظائف الأعضاء بالتطبيق السريري | عرض + أسئلة |
| 2 | التفكير السريري | التفكير التشخيصي في حالة تعليمية افتراضية | نقاش حالة |
| 3 | الصحة العامة | تحديات الرعاية الصحية في الأزمات | حوار وتطبيق |
| 4 | البحث العلمي | قراءة الأدلة والبحث والكتابة الطبية | ورشة تأسيسية |

المدة المستهدفة 45–60 دقيقة للقاء، محاضرة واحدة أسبوعيًا متى توفرت الموافقة والقدرة التقنية. كل المحاور والعناوين قابلة للتعديل بعد اختيار المتحدثين. لا تُعلن التواريخ قبل تأكيد المحاضر.

### 3. الفريق ومسؤولياته
| الوظيفة | المسؤولية |
|---|---|
| مدير البرنامج | اعتماد الرسالة والجدول والمحتوى وإذن التواصل |
| منسق العلاقات الدولية | إعداد قائمة الجهات، إرسال الدعوات المعتمدة، توثيق الموافقات |
| منسق المحتوى العلمي | تدقيق الأهداف والمستوى والمراجع، وتجنب تقديم استشارات مرضى |
| مسؤول العمليات التقنية | منصة الاجتماع، التسجيل، روابط الدخول، اختبار الهاتف والاتصال |
| مدير اللقاء | التعريف بالضيف وإدارة التوقيت والأسئلة |
| مسؤول التقييم | قياس الحضور والرضا والمشكلات التقنية |

يجوز جمع الأدوار في أشخاص أقل خلال التجربة مع وضوح المسؤوليات.

### 4. مراحل التنفيذ
1. **التأسيس:** اعتماد الاسم والملف التعريفي والهوية وصفحة البرنامج وقائمة الجهات.
2. **التحضير للتواصل:** مراجعة الجهات المحتملة وتحديد البريد الرسمي وملاءمة تخصصاتها، مع الامتناع عن المراسلة حاليًا.
3. **التواصل بعد الإذن:** دعوة تطوعية شخصية موجزة، مرنة في الموعد، دون مطالبة الجهة بالتزام أسبوعي دائم.
4. **توثيق الموافقات:** تثبيت اسم المتحدث وصفته المسموح نشرها، الموضوع، الوقت، اللغة، حقوق المواد والتسجيل.
5. **إعداد الجلسة:** أهداف تعلم محددة، وصف موجز، وقت الأسئلة، ومراجعة المواد العلمية.
6. **الاختبار التقني:** منصة اتصال موثوقة، خطة للصوت منخفض الاستهلاك، ومواعيد بديلة.
7. **فتح التسجيل:** فقط بعد تأكيد الجلسة والخصوصية والسعة، مع إرسال توجيهات واضحة للطلاب.
8. **التنفيذ:** مقدمة، محاضرة، أسئلة، استبيان مختصر، وملخص إن أمكن.
9. **المتابعة:** مراجعة المؤشرات والتغذية الراجعة قبل تكرار التجربة.

### 5. تجربة الطالب الرقمية
- صفحة رئيسية ثنائية اللغة عربي/إنجليزي مع حالة البرنامج الحقيقية.
- صفحة تعرض أهداف المبادرة، محاورها الأربعة، والنموذج التجريبي.
- لاحقًا: صفحة محاضرة منفصلة لكل موعد مؤكد، وتسجيل مختصر، ورسالة تأكيد.
- لاحقًا: موارد أو تسجيلات تُتاح بموافقة المتحدث، بحسب القدرة التقنية.
- لاحقًا: تقييم مختصر بعد اللقاء، دون استخدامه في ادعاء نتائج لم تتحقق.

### 6. التشغيل التقني والتكلفة
- الواجهة الحالية ثابتة وتستفيد من GitHub Pages دون إضافة خدمة مدفوعة للصفحة التعريفية.
- أي نظام لتسجيل الطلاب باستخدام Supabase يحتاج فحصًا مستقلًا للصلاحيات، وقواعد RLS، والحد الأدنى لجمع البيانات قبل تفعيله.
- اختيار منصة اللقاء وفق سعتها الفعلية والقيود المجانية عند بدء التنفيذ، وعدم افتراض سعة أو مدة غير متحققة.
- واجهة خفيفة تدعم الجوال، RTL وLTR، وتفضيل تقليل الحركة، ولا تعتمد على فيديو يبدأ تلقائيًا.
- التكلفة المباشرة للواجهة التعريفية: يمكن إبقاؤها ضمن الاستضافة الحالية؛ تكاليف اللقاءات/الإيميل/الترجمة ترتبط بالأدوات والأحجام المعتمدة لاحقًا.

### 7. الثقة وحماية البيانات
- لا تُنشر أسماء أو شعارات أو صفات شراكة لجامعة أو منظمة دون موافقة صريحة.
- لا يُطلب من المتحدث مشاركة بيانات مرضى حقيقية؛ تُستخدم حالات افتراضية أو منزوعـة التعريف ومناسبة تعليميًا.
- أي تسجيل فيديو أو صوت يتطلب موافقات مسبقة واضحة وإعلام الحضور.
- لا يُعلن عن شهادات أو ساعات معتمدة أو اعتماد أكاديمي دون موافقة وإجراءات مستقلة.
- حماية بيانات المتعلمين، وإعلان السياسة وطريقة حفظها وحذفها قبل فتح التسجيل.
- التنبيه بوضوح إلى أن المحتوى تعليمي وليس نصيحة طبية شخصية.

### 8. مخاطر عملية
| الخطر | التعامل المقترح |
|---|---|
| عدم موافقة أول عشر جهات | لا إعلان شراكات؛ توسيع القائمة لاحقًا بعد اعتماد الخطة |
| انقطاع الاتصال | مواد خفيفة وحوار صوتي وموعد احتياطي عند الإمكان |
| اختلاف المناطق الزمنية | تأكيد التوقيت كتابة بتوقيت غزة وتوقيت المتحدث |
| اعتذار المتحدث | سياسة تأجيل وإلغاء واضحة قبل إرسال روابط اللقاء |
| ضعف الترجمة | تحديد لغة اللقاء مسبقًا وتقديم مصطلحات مساعدة حيث يمكن |
| تجاوز سعة الاجتماع | تحديد الحد الأقصى والتسجيل المسبق بعد اختيار المنصة |

### 9. معايير نجاح مقترحة — وليست نتائج
- عدد الجهات التي خوطبت رسميًا بعد الإذن، والاستجابات الإيجابية.
- عدد المحاضرين والجلسات المؤكدة والمنفذة.
- عدد التسجيلات والحضور ونسبة الحضور إلى التسجيل.
- تقييم الطالب للفائدة ووضوح المحتوى عبر استبيان اختياري.
- الأعطال التقنية الرئيسية ونسبة حضور الطلاب عبر الهاتف.
- مدى استعداد المحاضرين للمشاركة مجددًا.

### 10. بوابات الاعتماد قبل الإطلاق
- اعتماد نص الدعوة والشركاء المستهدفين قبل المراسلة.
- تأكيد أول متحدث وموضوع وموعد.
- اختبار منصة اللقاء والتسجيل والخصوصية.
- مراجعة نص الإعلان بالمصطلحات الدقيقة: «محاضرة بضيافة متحدث» وليس «شراكة مؤسسية» إلا بإذن.
- إطلاق التسجيل والإعلان النهائي فقط بعد إتمام ما سبق.

### 11. مخرجات المرحلة الحالية
1. **الصفحة الرئيسية:** قسم بارز يعرّف بالبرنامج ويقود للتفاصيل.
2. **صفحة البرنامج:** global-lectures.html، ثنائية اللغة، برسوم تفاعلية خفيفة وخطة واضحة.
3. **هذا المستند:** مرجع إداري للتشغيل والمتابعة؛ لا يعادل إطلاق الخدمة أو توقيع شراكة.
