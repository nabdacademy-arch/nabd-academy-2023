# تشغيل المساعد الطبي القوي بلا رصيد OpenAI — NABD AI Tutor v3

**المطلوب:** تشغيل محاكاة الشرح الطبي والأسئلة التدريبية بالعربية والإنجليزية، بديلًا عن OpenAI API الذي ظهر رصيده $0.00. هذا الإصدار يستخدم **GroqCloud** لاستضافة نموذج \`openai/gpt-oss-120b\` للنصوص، و**Gemini 2.5 Flash** للصور التعليمية واحتياطًا للنصوص. اسم النموذج يتضمن OpenAI لأنه نموذج مفتوح الأوزان، **لكن المفتاح والفوترة هنا من Groq، وليس من OpenAI API**.

**تنبيه:** مجانية المزوّدين ضمن حصص وحدود تتغير؛ لا توجد سعة غير محدودة أو ضمان تشغيل تجاري مجاني للأبد. حد Groq المجاني المنشور لـ \`openai/gpt-oss-120b\` هو **30 طلبًا/الدقيقة، و1,000 طلب/اليوم، و8,000 رمز/الدقيقة** على مستوى حساب المؤسسة، مع حدود رموز يومية إضافية (راجع لوحة حسابك). Gemini Flash يدعم النصوص والصور بفئة مجانية محدودة، لكن حدود حسابك الفعلية تُعرض في Google AI Studio.

## التجهيز من الهاتف (بدون شحن OpenAI)

### 1. إنشاء مفتاح Groq مجاني
- افتح **https://console.groq.com/keys**، وسجّل حساب مطور Groq إذا لزم.
- أنشئ API Key واحفظه مؤقتًا في مكان خاص. **لا ترسله في ChatGPT ولا إلى GitHub أو ملف index.ts**.
- افتح مشروع الأكاديمية نفسه في Supabase Dashboard > **Edge Functions > Secrets**.
- أنشئ Secret بالاسم **\`GROQ_API_KEY\`**، والصق القيمة هناك وحدها.
- بذلك يمكن للمساعد **الإجابة عن الأسئلة النصية دون مفتاح OpenAI أو رصيد OpenAI**.

### 2. تفعيل دعم الصور والاحتياط (اختياري، موصى به)
- افتح **https://aistudio.google.com/apikey** وسجّل بحساب Google.
- أنشئ مفتاح Gemini API ضمن مشروع Google يدعم الفئة المجانية. فلسطين مدرجة في المناطق المدعومة رسميًا؛ قد تتغير أهلية الحساب وحدود الحصة.
- أضف في Supabase > Edge Functions > Secrets مفتاحًا باسم **\`GEMINI_API_KEY\`**.
- لا حاجة لوضع مفتاح Gemini داخل JavaScript أو إعدادات الموقع العامة.
- إذا أضفت المفتاحين: **Groq للنصوص** افتراضيًا، و**Gemini للصور** وللتحويل التلقائي عندما يكون Groq غير متاح مؤقتًا أو بلغ حدّه.
- إذا أضفت **Gemini وحده**: يعمل المساعد على النصوص والصور، حتى دون مفتاح Groq.
- إذا أضفت **Groq وحده**: يعمل الشرح النصي؛ وتظهر رسالة واضحة عند رفع صورة بدلاً من محاولة قراءتها بنموذج نصي.
- متغير **\`NABD_TUTOR_PRIMARY\`** اختياري: قيمته \`gemini\` تجعل Gemini النموذج الأساسي للنصوص، مع إبقاء Groq احتياطيًا.

### 3. استبدال كود الدالة الحالية
1. افتح **[الملف المستقل الكامل](../supabase/manual/nabd-tutor.ts)** في GitHub على فرع **main** بعد دمج النسخة.
2. اضغط **Raw**، ثم **نسخ الكل**.
3. ارجع إلى **Supabase Dashboard > Edge Functions > nabd-tutor > Code > index.ts**.
4. استبدل جميع أسطر \`index.ts\` بالكود الكامل ثم اضغط **Deploy updates**.
5. **لا تنشئ دالة جديدة ولا تغيّر رابط \`/functions/v1/smart-processor\`**؛ هذا هو عنوان الخدمة الذي يستخدمه موقع نبض.
6. لا تشغّل ملف SQL مجددًا؛ دالة الحصة موجودة أصلًا. لا تعطّل JWT أو سياسة حسابات الطلاب.

### 4. التحقق
- افتح صفحة التعلّم في أكاديمية نبض، وسجّل الدخول بحساب اختبار.
- أرسل سؤالًا نصيًا غير مرتبط ببيانات مريض: **«اشرح دورة الدم في القلب بمستوى سنة أولى طب مع سؤالين للتأكد من الفهم»**.
- يجب أن يعرض المساعد إجابة تدريبية، ويمكن أن تظهر علامة \`provider: groq\` أو \`gemini\` في رد الشبكة (لا حاجة لإرسال معلومات الشبكة الخاصة).
- إذا أضفت Gemini، جرب فقط صورة رسم تشريحي تعليمي منشور للعامة أو رسمًا من صنعك، وليس صورة مريض.
- إذا ظهر \`CONFIG_MISSING\`: لم يُعثر على مفتاح Groq ولا Gemini في أسرار الدالة.
- \`PROVIDER_KEY_INVALID\`: المفتاح غير صالح. \`PROVIDER_RATE_LIMIT\`: حدود الخدمة المجانية/المؤقتة. \`IMAGE_PROVIDER_UNAVAILABLE\`: Gemini غير مُعَدّ.
- \`PROVIDER_UPSTREAM_ERROR\`: خلل مؤقت لدى المزوّد. إذا توفر الاثنان، يحاول النظام التبديل تلقائيًا.

## حماية وخصوصية
- يُرسَل **السؤال والنصوص التعليمية/الصورة المرفوعة** إلى المزوّد المحدد؛ ليست هذه معالجة دون خادم ولا داخل جهاز الطالب. **لا ترسلوا بيانات مرضى أو صورًا سريرية تعريفية أو سجلات صحية**.
- تقول Google إن محتوى الفئة المجانية قد يُستخدم لتحسين منتجاتها؛ لذا ينبغي استخدام Gemini فقط لمواد عامة أو أمثلة مجهولة وموافق عليها.
- تقول Groq إن مدخلات/مخرجات الاستدلال لا تُحفظ افتراضيًا إلا في حالات محددة مثل مراقبة إساءة الاستخدام أو الأعطال؛ اقرأ سياسة البيانات وحماية الخصوصية، ولا تعتبر ذلك إذنًا برفع ملفات مرضى.
- هذا مساعد **تعليمي** وليس مرجعًا لعلاج المرضى، ولا يمنح شهادات أو أحكامًا على كفاءة سريرية.
- يظل تسجيل الدخول إلى Supabase وفحص حصة ستة طلبات لكل طالب في الدقيقة وصلاحيات الحسابات وCORS مفعلًا. التحويل إلى المزوّد الاحتياطي لا يخصم طلبًا ثانيًا من حصة الطالب.
- لا يستدعي الإصدار الجديد \`OPENAI_API_KEY\` إطلاقًا، ويمكن ترك السر القديم دون استخدام حتى تتأكد من نجاح البديل، ثم إزالته بقرار إداري.
